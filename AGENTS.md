# Project rules
- UI and project documentation use Traditional Chinese. Do not use emoji.
- Use restrained typography, warm neutral colors, clear borders, and purposeful layouts. Avoid gratuitous gradients and decorative cards.
- This is a static SPA for GitHub Pages. Use relative asset URLs and hash routes.
- Never describe static validation as in-game verification.
- Keep map files in Google Drive. Never commit local handoff files or private data.
